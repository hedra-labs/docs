---
title: "Create and refine images"
description: "Generate and refine images in a Hedra Space by briefing the agent, adding references and Elements for identity or style, and iterating on the canvas."
---

Use the Agent when an image is part of a larger goal, needs research, or will
benefit from conversational iteration.

<Steps>
  <Step title="Start a Space">
    Open [Hedra](https://www.hedra.com/app/home) and select **New Space**.
  </Step>
  <Step title="Describe the outcome">
    Include the subject, composition, environment, visual direction, format, and
    constraints that matter.
  </Step>
  <Step title="Add visual context">
    Add references for source media or mention an Element with `@` when identity,
    product fidelity, or a recurring style should be preserved.
  </Step>
  <Step title="Review on the canvas">
    Compare outputs, select the useful result, and ask the agent for a targeted edit
    or a new direction.
  </Step>
</Steps>

```text
Create a 4:5 launch image for this speaker.
Preserve the product shape and logo exactly, place it on a brushed aluminum
surface, and use hard morning light with long geometric shadows.
```

## Iterate without losing context

In a Space, refer to the selected image or the previous direction:

```text
Keep the camera and product placement. Change only the background to a
deep red studio sweep and make the shadows softer.
```

Clear, bounded changes make it easier to preserve the parts that already work.

<Tip>
  Prefer direct model and output controls? Use the
  [manual Image tool](/pages/app/getting-started/manual-image).
</Tip>
