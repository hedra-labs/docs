---
title: "Create an Element"
description: "Save reusable visual context for characters, environments, styles, outfits, and brand identities."
---

Elements give frequently reused visual context a stable name that you can mention
in agent and manual-tool prompts.

## Create an Element

<Steps>
  <Step title="Open the Elements library">
    Select **Library**, then choose **Elements**.
  </Step>
  <Step title="Open Create Element">
    Select the **Create element** card.
  </Step>
  <Step title="Add references">
    Add up to 10 PNG, JPG, or WebP images, each up to 10 MB. Use images that agree
    about the subject or visual identity you want to preserve.
  </Step>
  <Step title="Name and classify it">
    Enter a unique `@name`, then choose **Character**, **Environment**, **Style**,
    **Outfit**, or **Brand Identity**.
  </Step>
  <Step title="Describe the invariant">
    Optionally explain what the agent should preserve and which variation is
    acceptable, then select **Save**.
  </Step>
</Steps>

## Use an Element

Type `@` in a Space or manual image/video prompt and select the Element.

```text
Place @field-jacket on @maya in a foggy coastal environment.
Preserve the jacket construction and Maya's facial identity.
```

## Reference quality

- Use sharp images without heavy compression.
- Include useful angles when shape matters.
- Avoid mixing conflicting identities or styles in one Element.
- Crop tightly enough that the intended subject is obvious.
- Use the description to distinguish what is fixed from what may change.

<Tip>
  Use an Element for recurring visual identity, a Skill for recurring instructions,
  and an ordinary reference for one-off source media.
</Tip>
