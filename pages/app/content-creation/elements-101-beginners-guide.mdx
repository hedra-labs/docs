---
title: "Elements basics"
description: "Learn when to save visual context as a reusable Element."
---

An Element is reusable visual context with a stable `@name`. It helps the agent or
a manual inference tool recognize something you use repeatedly.

## Element types

- **Character** — a recurring person, creature, or persona;
- **Environment** — a location or set;
- **Style** — a visual treatment or art direction;
- **Outfit** — clothing that should remain recognizable;
- **Brand Identity** — products, marks, packaging, or other brand-specific context.

## Create and use an Element

<Steps>
  <Step title="Open Library → Elements">
    Select **Create element**.
  </Step>
  <Step title="Add clear references">
    Add up to 10 PNG, JPG, or WebP images, each up to 10 MB.
  </Step>
  <Step title="Name and describe it">
    Choose a type, add a useful `@name`, and explain what should remain invariant.
  </Step>
  <Step title="Mention it in a prompt">
    Type `@` and select the Element in a Space or manual image/video tool.
  </Step>
</Steps>

```text
Create a three-shot winter lookbook with @maya, @field-jacket,
and @snow-lodge. Keep Maya's facial identity and the jacket construction exact.
```

## Element or reference?

Use a **reference** for one task. Create an **Element** when the same identity,
product, environment, or visual rule should be easy to reuse.

See [Give the agent visual context](/pages/app/getting-started/references-and-elements)
for the complete context model.
