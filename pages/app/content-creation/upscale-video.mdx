---
title: "Upscale a video"
description: "Create a higher-resolution derivative while preserving the original video."
---

Upscaling creates a new, enhanced version of an existing video. It does not replace
or modify the source.

## Upscale in the Video tool

<Steps>
  <Step title="Open Upscale mode">
    Go to **Manual tools → Video**, then choose **Upscale**.
  </Step>
  <Step title="Add the source video">
    Upload a video or select one from the Library.
  </Step>
  <Step title="Choose the output">
    Select a model and target resolution supported by the source and your plan.
  </Step>
  <Step title="Generate">
    Start the upscale, then compare the result with the original before downloading
    or using it in Composer.
  </Step>
</Steps>

## What upscaling can improve

- output resolution;
- edge and texture clarity;
- perceived sharpness on larger displays.

It cannot reliably restore detail that was never present. Heavy compression,
motion blur, or very low source resolution can limit the result.

<Tip>
  Start from the cleanest available source rather than repeatedly upscaling an
  already processed derivative.
</Tip>
