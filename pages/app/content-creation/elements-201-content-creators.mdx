---
title: "Design stronger Elements"
description: "Build focused visual anchors that remain useful across compositions, outfits, and environments."
---

Strong Elements communicate one clear visual identity. Weak Elements bundle
several competing subjects, styles, or environments and force the model to guess
which details matter.

## One purpose per Element

Separate identity from variables you expect to change:

- a **Character** should anchor the person, not one elaborate outfit and location;
- an **Outfit** should make its construction easy to see;
- an **Environment** should describe the set rather than a foreground character;
- a **Style** should demonstrate a repeatable treatment across more than one subject;
- a **Brand Identity** should make product shape, packaging, color, and marks legible.

## Choose useful anchors

- Include the subject at a scale where important details are visible.
- Use consistent images that agree about identity and design.
- Add more than one angle when three-dimensional shape matters.
- Avoid heavy filters, motion blur, and occlusion unless they are part of the
  identity you intend to preserve.
- Use the description to name fixed attributes and acceptable variation.

## Prevent drift

When a result drifts:

1. simplify the prompt to isolate the Element;
2. remove conflicting references;
3. use a clearer or tighter anchor image;
4. separate outfit, environment, and style into their own Elements;
5. test the Element in a neutral composition before a complex scene.

## Combine Elements deliberately

```text
Use @maya for identity, @field-jacket for wardrobe, and @snow-lodge
for the environment. Apply @winter-editorial only to lighting, color,
grain, and lens treatment.
```

The prompt assigns a role to each Element instead of asking the model to infer how
they should interact.

<Note>
  Reference capacity is model-specific and changes over time. Check the selected
  model's live reference panel instead of targeting a fixed maximum.
</Note>
