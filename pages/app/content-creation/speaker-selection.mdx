---
title: "Choose the speaker in an avatar scene"
description: "Make the intended speaker explicit when a reference image contains multiple people."
---

For a multi-person avatar image, the selected model may expose a speaker control
on the image reference.

## Workflow

1. Open **Manual tools → Video** and choose **Avatar**.
2. Select a model that supports the image and audio inputs you need.
3. Add the multi-person image as the visual reference.
4. If **Select Speaker** is available, place the speaker indicator over the intended
   face and size it closely enough to avoid overlap.
5. Add the audio and state in the prompt which person should perform it.
6. Generate a short test and confirm the correct face is speaking.

## Better multi-person references

- Keep faces separated and large enough to identify.
- Avoid crossing faces, heavy occlusion, and extreme profiles.
- Use a short sample before committing to a long generation.
- If the wrong person speaks, crop or simplify the reference and select again.

<Note>
  Speaker controls are model-specific. If the selected model does not expose one,
  use a clearer single-person reference or choose another avatar model.
</Note>
