Manual tools are direct creative interfaces. Use one when you already know what
you want to generate or edit and want to choose the model, inputs, and output
settings yourself.

The Agent is conversational and can coordinate a broader workflow. Manual tools
perform one defined operation at a time.

| Tool | Use it when |
| --- | --- |
| **[Image](/pages/app/getting-started/manual-image)** | You want to generate or edit an image with a specific model, references, aspect ratio, resolution, or batch size. |
| **[Video](/pages/app/getting-started/video-models)** | You want to generate, animate, transition, create an avatar performance, or upscale video with explicit model controls. |
| **[Speech](/pages/app/content-creation/create-audio)** | You want to select a voice and generate spoken audio from a script. |
| **[Edit Video](/pages/app/content-creation/edit-videos-in-composer)** | You want to arrange clips and audio on a timeline and export a finished video. |

## How manual tools work

The exact controls depend on the selected model or operation, but the pattern is
consistent:

1. Choose the tool and model or operation.
2. Add the required references or source media.
3. Enter the prompt, script, or editing instructions.
4. Set the supported output controls.
5. Generate or export, then review the result in the Library.

<Note>
  The Library stores and organizes work; it is not a manual tool. You may select
  Library assets as inputs or find completed outputs there.
</Note>
