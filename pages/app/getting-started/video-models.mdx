## Start with a mode

| Mode | Use it when |
| --- | --- |
| **All** | You need general text-to-video, image-to-video, reference-driven video, or another model-specific workflow. |
| **Avatar** | A person or character should perform speech or audio from a reference image. |
| **Transition** | You want motion that connects a defined start and end state. |
| **Upscale** | You already have a video and need a higher-resolution derivative. |

## Compare models by capability

Before choosing a model, check:

- **Accepted references** — image, video, audio, start frame, end frame, or multiple
  visual references;
- **Output controls** — aspect ratio, resolution, duration, and batch size;
- **Audio behavior** — silent output, generated sound, or supplied audio;
- **Identity fidelity** — how closely the result must preserve a person, product,
  or source frame;
- **Motion needs** — subtle animation, camera movement, performance, transition,
  or complex action;
- **Cost and speed** — shown in the live selector and generation controls.

## Use references intentionally

Reference requirements change with the selected model. The reference panel updates
to show what that model can accept. Do not assume a prompt-only model can preserve
identity as reliably as a reference-driven workflow.
