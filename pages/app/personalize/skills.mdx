---
title: "Skills"
description: "Create, edit, and browse reusable skills your Hedra agent can invoke."
---

A **skill** is a reusable instruction set your agent can invoke on demand — think of it as a saved recipe (a prompt plus optional configuration) that you can drop into any chat. Use skills to lock in a workflow you repeat often, such as a specific style guide, a research template, or a content-generation format.

The **Skills** tab in [Personalize](/pages/app/personalize/overview) shows two sections:

- **Your skills** — private skills you've created. Only you can see or invoke these.
- **From Hedra** — a read-only catalog of skills curated by Hedra that any user can try.

## Create a new skill

<Steps>
  <Step title="Open Personalize">
    Click **Personalize** in the sidebar and stay on the **Skills** tab.
  </Step>
  <Step title="Click New skill">
    Select **New skill** at the top right. A creation dialog opens.
  </Step>
  <Step title="Fill in the skill">
    Give the skill a name and description, then write the instructions in the editor. Add any optional configuration fields your skill needs (for example, a target audience or a tone).
  </Step>
  <Step title="Save">
    Save the skill. It appears immediately in **Your skills** and becomes available in the chat command menu as `/skillname`.
  </Step>
</Steps>

## Edit or delete a skill

Hover any skill in **Your skills** and click the **pencil** icon on the card to open the edit dialog. From there you can update the instructions and configuration, or delete the skill.

<Note>
  Editing a skill in Personalize uses the same dialog as editing from the chat command menu, so changes are reflected everywhere the skill is used.
</Note>

## Browse the Hedra catalog

Skills under **From Hedra** are read-only. Click a card to open its detail view and see what the skill does, then invoke it from any chat with `/skillname`. You can duplicate a Hedra skill into **Your skills** to customize it — the duplicate becomes a private skill you fully own.

## Search

Use the search input at the top of the tab to filter both **Your skills** and **From Hedra** by name or description.
