Generate images, video, and audio with over 100 models through one API. Fund
your wallet, then every model runs through the same three requests: submit a
job, poll it, download the output. Browse the
[model catalog](https://www.hedra.com/develop/models) to pick one.

### Step 1: Create an API key

Generate a key in the [developer console](https://www.hedra.com/develop/api-keys).

```
Authorization: Key <key_id>:<secret>
```

### Step 2: Fund the API wallet

The API bills a **prepaid wallet** held in US dollars. (This USD balance is
separate from your Hedra Studio credit balance.) Add funds in the
[developer console](https://www.hedra.com/develop/billing), and read the wallet
any time with `GET /balance`.

Until you add funds, `POST /models/{id}` will return `402 INSUFFICIENT_BALANCE`.

### Step 3: Pick a model

`GET /models` lists every model with its `id` and display `name`, so a model
you know by name ("GPT Image 2") gives you the id for its submit path
(`POST /models/gpt-image-2`). Each model publishes its typed input schema at
`GET /models/{id}/openapi.json`.

```bash
curl https://api.hedra.com/v3/models -H "Authorization: Key $HEDRA_KEY"
```

Optionally, to see a job's price before you submit it, ask for an estimate:

```bash
curl -X POST https://api.hedra.com/v3/models/gpt-image-2/estimate \
  -H "Authorization: Key $HEDRA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"input": {"prompt": "a space cat", "quality": "medium", "aspect_ratio": "1:1", "resolution": "1K"}}'
```

### Step 4: Submit, poll, download

Every generation follows the same lifecycle: submit a job, poll it, then read
the output URL.

```bash
# 1. Submit: capture the job id from the 202 response
JOB_ID=$(curl -sS -X POST https://api.hedra.com/v3/models/gpt-image-2 \
  -H "Authorization: Key $HEDRA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"input": {"prompt": "a space cat", "quality": "medium", "aspect_ratio": "1:1", "resolution": "1K"}}' | jq -r .job_id)

# 2. Poll until status is COMPLETED (or FAILED)
curl https://api.hedra.com/v3/jobs/$JOB_ID/status -H "Authorization: Key $HEDRA_KEY"

# 3. Read the result: outputs[].url holds the generated file
curl https://api.hedra.com/v3/jobs/$JOB_ID -H "Authorization: Key $HEDRA_KEY"
```
