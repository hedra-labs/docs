Generate images, video, and audio through one API, with over 100 models
including Veo 3.1, Seedance 2.0, Kling V3, GPT Image 2, Nano Banana Pro, and
ElevenLabs V3. You call every model with one API key and the same three
requests: submit a job, poll it, download the output. Hedra charges every job to
one prepaid wallet. Input fields have the same names across models, such as
`prompt`, `aspect_ratio`, `resolution`, `duration_ms`, and `start_image`, and
each model's schema lists the values that model accepts. To switch models,
change the model id and choose values from the new model's schema. Browse the
[model catalog](https://www.hedra.com/develop/models) to pick one.

### Step 1: Create an API key

Generate a key in the [developer console](https://www.hedra.com/develop/api-keys).
Every request authenticates with it:

```
Authorization: Key <key_id>:<secret>
```

### Step 2: Fund the API wallet

The API bills a **prepaid wallet** held in US dollars. It is separate from your
Hedra Studio balance, and a workspace starts with **$0.00** in it. Until you
add funds, `POST /models/{id}` returns `402 INSUFFICIENT_BALANCE`.

Add funds in the [developer console](https://www.hedra.com/develop/billing),
and read the wallet any time with `GET /balance`.

<Note>
  Uploading inputs with `POST /files` is free and succeeds on an empty wallet,
  so you can upload inputs before you add funds. `POST /models/{id}` checks the
  balance when you submit a job.
</Note>

### Step 3: Pick a model

`GET /models` returns each model's `id` and display `name`, such as
`gpt-image-2` for "GPT Image 2". Submit jobs with `POST /models/{id}`, for
example `POST /models/gpt-image-2`. `GET /models/{id}/openapi.json` returns a
model's input schema.

```bash
curl https://api.hedra.com/v3/models -H "Authorization: Key $HEDRA_KEY"
```

To see a job's price before you submit it, request an estimate with
`POST /models/{id}/estimate`:

```bash
curl -X POST https://api.hedra.com/v3/models/gpt-image-2/estimate \
  -H "Authorization: Key $HEDRA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"input": {"prompt": "a space cat", "quality": "medium", "aspect_ratio": "1:1", "resolution": "1K"}}'
```

### Step 4: Submit, poll, download

Every job follows the same steps: submit it, poll it, then read the output URL.

```bash
# 1. Submit: capture the job id from the 202 response
JOB_ID=$(curl -sS -X POST https://api.hedra.com/v3/models/gpt-image-2 \
  -H "Authorization: Key $HEDRA_KEY" \
  -H "Content-Type: application/json" \
  -d '{"input": {"prompt": "a space cat", "quality": "medium", "aspect_ratio": "1:1", "resolution": "1K"}}' | jq -r .job_id)

# 2. Poll until status is COMPLETED (or FAILED)
curl https://api.hedra.com/v3/jobs/$JOB_ID/status -H "Authorization: Key $HEDRA_KEY"

# 3. Read the result: outputs[].url holds the generated file
curl https://api.hedra.com/v3/jobs/$JOB_ID -H "Authorization: Key $HEDRA_KEY"
```

Hedra keeps outputs for at least **48 hours** after a job completes. Download
them to your own storage, or pass an output's `asset_id` as input to the next
job.
