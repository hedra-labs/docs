---

`POST /v3/chat/completions`

Use a Hedra key with `chat:write` and a funded API wallet. See the
[Chat Completions request guide](/pages/developer/v3/chat-completions#send-a-request) for
supported fields, responses, SDK examples, and compatibility differences.

These routes serve supported language models. They are separate from the
asynchronous image, video, and audio job-submission API. Do not assume every
field or behavior of the upstream SDK's API is supported.
