---
title: "Generate a video"
description: "Run video inference on the Hedra v3 API with a model-specific request and the shared asynchronous job lifecycle."
---

Generate a video from text. To animate an image, add `input.start_image` using an uploaded file or a completed image job’s asset reference.

[Open Veo 3 in the playground](https://www.hedra.com/develop/models/video/veo-3)
to explore this model's inputs. The **API** tab generates request code from the
same model schema. To reproduce the example below, enter its inputs before running.

## Submit a job

Set `HEDRA_API_KEY` as shown in the [quickstart](/pages/developer/v3/quickstart).
This example submits to `veo-3`; its payload is not interchangeable with
another model's schema.

```bash
curl --fail-with-body -X POST https://api.hedra.com/v3/models/veo-3 \
  -H "Authorization: Key $HEDRA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"input":{"prompt":"A camera moves slowly around an industrial inspection rig","aspect_ratio":"16:9","resolution":"720p","duration_ms":4000,"quality":"fast"}}'
```

The `202` response contains a `job_id`. Follow the
[submit, wait, and download workflow](/pages/developer/v3/quickstart#submit-wait-and-download),
or use [webhooks](/pages/developer/v3/webhooks). Check output status before
retrieving URLs. To estimate this request first, send its body to
`POST /v3/models/veo-3/estimate`.

## Inputs and limits

Inspect `GET /v3/models/veo-3/openapi.json` for accepted fields, defaults,
and constraints. See [Files and outputs](/pages/developer/v3/files) for media
references and [Quality levels](/pages/developer/v3/quality-levels) for models
that expose a tier selector.
