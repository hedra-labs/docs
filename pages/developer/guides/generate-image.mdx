---
title: "Generate an Image"
description: "Generate images from text prompts with the Hedra API — submit a request, poll for completion, and discover per-model resolutions and defaults."
---

All examples use the base URL `https://api.hedra.com/web-app/public` and require an `X-API-Key` header.

```bash
export HEDRA_API_KEY="your_api_key"
```

## Generate an image from a text prompt

```bash
curl -X POST https://api.hedra.com/web-app/public/generations \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $HEDRA_API_KEY" \
  -d '{
    "type": "image",
    "text_prompt": "A golden retriever sitting in a field of sunflowers",
    "model_slug": "google/nano-banana-pro",
    "aspect_ratio": "16:9",
    "resolution": "2K"
  }'
```

### Required fields

| Field | Description |
|-------|-------------|
| `type` | Set to `"image"` |
| `text_prompt` | The text description of the image to generate |
| `model_slug` | The model slug to use (see `GET /models?types=image`) |

### Optional fields

| Field | Description |
|-------|-------------|
| `aspect_ratio` | e.g. `"16:9"`, `"9:16"`, `"1:1"` |
| `resolution` | A resolution supported by the selected model |
| `batch_size` | Generate 1-8 variations at once (default: 1) |
| `enhance_prompt` | Set to `true` to automatically enhance the prompt |

<Note>
  When `batch_size` is greater than 1, include a `generation_ids` array containing
  one client-generated UUID for each variation.
</Note>

## Poll for completion

The response includes a generation `id`. Poll until `status` is `"complete"`:

```bash
curl https://api.hedra.com/web-app/public/generations/{generation_id}/status \
  -H "X-API-Key: $HEDRA_API_KEY"
```

When complete, the response includes an `asset_id` for the generated image.

## Available image models

Use `GET /models?types=image` to list image models and their current slugs,
supported resolutions, aspect ratios, and input requirements.

```bash
curl "https://api.hedra.com/web-app/public/models?types=image" \
  -H "X-API-Key: $HEDRA_API_KEY"
```

Each model also advertises the value it substitutes when you omit
`aspect_ratio` or `resolution`. If a field publishes a JSON Schema `default`,
that is the exact setting your request will render and be billed at when the
field is absent — for example, Seedream 4.0 defaults to `"1:1"` at `2160p
(4K UHD)`. Check these before shipping a prompt-only submit so the output
matches your expectations.

The `text_prompt` field publishes `minLength` and `maxLength` for models whose
provider documents a cap — for example, GPT Image accepts up to 32,000
characters, Imagen 4 up to 5,000, Recraft v3 up to 1,000. Validate prompt
length client-side to turn what would be a mid-generation rejection into a
field-level error before you submit.
