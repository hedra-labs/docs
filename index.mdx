## Docs and console

Use these docs for integration guides, examples, and the API reference.
[Open the console](https://www.hedra.com/develop) to try models, inspect jobs,
and manage API access and billing. To start an integration,
[get an API key](https://www.hedra.com/develop/api-keys).

## From inference to post-training

World Model Runtime is Hedra's engine for multimodal workloads. Hedra Training connects
model adaptation and evaluation with deployment. GPU Sandboxes provide isolated
compute for custom code and pipelines.

Training and GPU Sandboxes are currently **research previews**. See
[Hedra's platform overview](https://www.hedra.com/) or
[contact the engineering team](https://www.hedra.com/enterprise) to discuss access
and supported workloads. For bringing your own model or deploying on your own
infrastructure, see [deployment options](https://www.hedra.com/inference).

## Existing integrations

Building a new integration? Use v3. If you use the `/web-app/public` API,
read [Migrate from v2 to v3](/pages/developer/v3/migrate-from-v2).
