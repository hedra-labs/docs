Hedra is an a16z-backed research company building models and infrastructure for
multimodal and physical AI. Build a specialized model with Hedra researchers,
bring an existing model to discuss serving, or start with a catalog model through
the self-service **v3 API**.

The API supports image understanding, reasoning, and image, video, and audio
generation, backed by a prepaid API wallet.

## Docs and console

Use these docs for integration guides, examples, and the API reference.
[Open the console](https://www.hedra.com/develop) to try models, inspect jobs,
and manage API access and billing. To start an integration,
[get an API key](https://www.hedra.com/develop/api-keys).

## Build a model for your task and hardware

With **RSI as a service**, forward-deployed Hedra researchers work inside your
team to customize and optimize a model, set up data capture and evaluations,
and connect training to production serving. The service is hands-on, with
research and inference under one roof.

[Learn how custom model engagements work](/pages/developer/v3/custom-models),
including how to bring an existing model to Hedra inference.
